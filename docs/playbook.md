# KALAU LAH! Playbook

## 1. Ideation framework (run every idea through this)
1. **Truth:** the specific thing every Malaysian has lived through ("Mak kata 'tak nak' then eats your fries"). If you can't name the exact moment, drop it.
2. **POV line:** "POV: ..." in under 8 words, readable in 1.5 s.
3. **Escalation ladder:** 3 beats, each more exaggerated but still recognisable (real, then a bit much, then absurd).
4. **Twist:** the punchline must come from inside the situation (reversal, callback, character revealing the truth). Ban list: "and then he woke up", random explosions, generic "relatable" captions.
5. **Tag test:** who would a viewer tag? (sibling, the "otw" friend, mum). No answer means a weak idea.
6. **Cost check:** ≤3 backgrounds, ≤3 characters, reuse ≥70% of assets.
Score each 1–5 on Relatability, Twist, Cost (5 = cheapest). Produce ideas scoring ≥12.

## 2. Script template
```
EPNNN: <title> | Pillar: <n> | <duration>s | BG: <list> | Cast: <list>
HOOK (0–2s): POV text: "..."   SFX: ...
| t | Scene | Who | Bubble / on-screen text | Expression / action | SFX |
SETUP (2–8s) ...
ESCALATION 1 / 2 / 3 ...
PUNCHLINE (last 3–5s) ... hold 1s on the reaction face, then end card.
```
Bubble rules: ≤10 words, one idea per bubble, reading time ≈ 0.06 s/char + 0.4 s. Text messages, phone notifications, receipts and calendars are cheap, high-impact "dialogue".

## 3. Storyboard + animation workflow (≈5 h/week)
| Step | Time | Output |
|---|---|---|
| Pick idea, write script with template (Claude) | 0.5 h | `EPISODE.md` |
| Animatic: Claude builds `animatic.html` from the script, reusing rigs/BGs | 0.5 h review | 9:16 mp4 preview with SFX |
| Polish in CapCut/Canva (or post the animatic directly) | 2–3 h | final 1080×1920 |
| SFX/music pass (library in `assets/sfx`) | 0.5 h | mixed audio, -14 LUFS |
| Caption, cover frame, schedule | 0.5 h | posted |
Animation vocabulary (reusable): blink, 2-frame mouth flap, head bob, squash-pop entrance, camera shake, punch-in zoom, freeze-frame, speed lines, sweat drop, sticker/phone overlays.

## 5. Captions + publishing
- **Caption formula:** relatable line in their voice + tag prompt + 3–6 hashtags. ≤150 chars before the hashtags.
  e.g. "Mak: 'Mak tak nak.' Also Mak: 🍟🍟🍟 Tag adik-beradik yang sama perangai. #KalauLah #POV #MalaysianTikTok #RelatableMY #Mak"
- **Core tags:** #KalauLah #POV #Malaysia #MalaysianTikTok #LawakMalaysia, plus 1–2 pillar tags (#BalikKampung #OfficeLife #Mamak #Raya).
- **Cover:** reaction face + POV text (big, top third). First frame = hook frame.
- **Posting:** TikTok + IG Reels + YT Shorts from one export. Best slots: weekdays 8–10 pm MYT, Sat/Sun 12–2 pm (test and adjust). Reply to the top comments with a "Part 2?" tease.
- **Series hooks:** recurring tags like "Mak Series", "Office Series" and "Mamak Series" build bingeable playlists.
- **Topical:** plan Raya, Merdeka, CNY, Deepavali, year-end and payday (25th) episodes 2 weeks ahead.
